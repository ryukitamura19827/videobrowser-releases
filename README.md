# ねこねこプレイヤー 配布用

ねこねこプレイヤー（Windows 版）のインストーラーと、アプリの自動更新が見る `latest.yml` を置く場所です。

- 入れるとき: [Releases](https://github.com/ryukitamura19827/videobrowser-releases/releases/latest) から `NekonekoPlayer-Setup-X.Y.Z.exe` を落としてダブルクリック。
- 2回目からは、アプリの中（設定 → アップデート）から更新できます。
- ここには手で置かず、本体リポジトリの GitHub Actions が版を上げるたびに自動で公開します。
